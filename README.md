# Programming and Engineering

Este repositório contém materiais de estudo, exercícios e projetos práticos focados em programação e desenvolvimento de software. O objetivo é documentar o aprendizado e prática de diferentes tecnologias.

## 📂 Estrutura do Repositório

O conteúdo está organizado por tecnologias e módulos de estudo:

### 🌐 HTML & CSS
Diretório dedicado ao estudo de desenvolvimento web front-end.
- **HTML-CSS-Modulo01**: Contém aulas e exercícios introdutórios sobre estrutura e estilização de páginas web.

### 🐍 Python
Diretório focado na linguagem de programação Python.
- **Python-Basico**: Coleção de scripts cobrindo conceitos fundamentais como:
  - Tipos de dados (int, float, bool, strings)
  - Estruturas de controle (if, else, while, for)
  - Manipulação de listas e tuplas
  - Exercícios práticos (Calculadora, Jogo da Palavra Secreta, Lista de Compras, etc.)

## 🚀 Como usar

Sinta-se à vontade para explorar os diretórios e executar os códigos para ver como funcionam.

**Para executar os scripts Python:**
Certifique-se de ter o Python instalado e rode o comando (exemplo):
```bash
python Python/Python-Basico/calculadora_simples_while.py
```
